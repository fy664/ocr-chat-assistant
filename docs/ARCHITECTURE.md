# 言外项目骨架

言外是 Windows 上的 PySide6 桌面应用。用户框选聊天窗或粘贴对话，应用整理带发言者的记录，生成整段总结、最近事件、语义解读和回复建议。

## 入口与模块

| 模块 | 职责 |
| --- | --- |
| `app/main.py`、`app/ui/decoder_window.py` | 启动、选区与采集操作、可编辑记录和结果界面 |
| `app/ui/window_picker.py`、`app/capture/window_capture.py` | 窗口选择、预览、相对坐标选区。Qt 窗口采集不可用时可使用屏幕选区 |
| `app/analysis/decoder.py`、`app/analysis/capture_session.py` | 协调单次读取与滚动会话、采样和重复帧检测、收尾与模型任务 |
| `app/analysis/workers.py`、`app/ocr/` | 后台 PaddleOCR。滚动采集以有界 FIFO 队列处理帧 |
| `app/analysis/chat_layout.py` | 从 OCR 坐标及图像推断会话列表、标题区和消息区，识别头像与昵称并判定会话类型 |
| `app/analysis/stitch.py` | 按滚动方向拼接 OCR 行，保留发言者线索和无法确认的断点 |
| `app/agent/` | 编排历史摘要、当前语义分析、最近事件和回复建议 |
| `app/llm/`、`app/models/schemas.py` | 对接模型、流式响应、JSON 修复和 Pydantic 数据结构 |
| `app/ui/floating_panel.py` | 展示总结、事件原文证据、语义分析和可复制回复 |

## 从窗口到对话记录

1. 选定聊天窗口后，框选左侧会话列表和右侧会话标题、聊天记录。窗口采集输出所选窗口的像素，屏幕选区使用当前桌面像素。
2. 本地 OCR 提取文本及位置。布局识别以分隔线、背景变化和文本分布定位会话列表与消息区。标题和左栏选中项帮助定位当前会话，其他会话的名称和预览从记录中排除。识别到输入区时也排除输入区。
3. 在消息区边缘寻找头像，结合头像附近的昵称、身份标记及对齐位置归属消息。跨帧复用同一会话中的头像特征。没有可信昵称时，保留参与者或位置标签。明显的非文字消息可以留下图片或表情占位。
4. 标题成员人数、群聊标记和不同发言者是群聊线索。私聊标记或可见的双边发言是私聊线索，后者显示为推测。已有会话名称且类型证据不足时显示「类型待确认」。头像特征用于同一会话的记录拼接。
5. 「画面」页使用同一选区的实时预览。窗口采集从 Qt 视频源取最新帧，屏幕选区以较低频率更新。预览暂停或结束时清空画面。OCR 使用独立采样节奏，拼接已有重叠记录。没有可靠重叠时标记断点。识别到会话标题改变时结束本轮采集，保留原会话。关闭窗口或点击结束也会收尾。采集范围是用户实际滚动并成功识别的可见消息。

## 从对话记录到解读

1. 用户点击「解读这段对话」，或勾选「采集后自动解读」后完成采集。模型请求在后台运行，编辑器中的记录可校正后重新解读。
2. Agent 为文本行加上稳定的消息编号。超出单次上下文预算时，按消息边界分段归纳旧记录，将累计历史摘要和最近原文一起交给最终模型。启用视觉时，模型可同时查看消息区截图。滚动采集最多附带本轮最后一张成功识别的画面。
3. 模型输出整段总结、时间线、决定和待确认事项，再从最近原文提取当前事件、相关参与者和回复建议。Agent 校验事件引用编号并回填对应原文。结构化结果通过校验后才进入界面。
4. 本地阶段处理画面、头像特征、OCR 和拼接。解读阶段复用本轮模型连接，完成后释放连接。回复按钮把草稿复制到剪贴板。
5. 退出时立即停止采集并请求取消后台任务。界面保持响应，等正在执行的 OCR 或模型请求安全退出后关闭。

## 验证

`tests/test_chat_understanding.py` 使用合成窗口、OCR 桩和 Mock 模型覆盖整窗群聊与私聊识别、侧栏和草稿过滤、低证据类型、切换保护、历史归纳及自动解读。窗口采集、采样、拼接和旧版模块各有回归测试。运行方式见 [README](../README.md#测试)。
